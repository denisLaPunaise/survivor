# Recettes de construction

Un script par morceau de ville. Chacun reconstruit à l'identique ce qu'il
décrit dans `Workspace`, en détruisant d'abord ce qui répond au contrat de
nommage (pas une liste de noms qui se périme), puis se mesure lui-même.

La ville n'est ni dans Git ni dans Rojo : ces recettes sont sa seule
sauvegarde. Ce dossier est hors du projet Rojo et hors de `selene src`.
